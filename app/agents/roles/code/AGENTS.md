# AGENTS.md — 最小上下文契约

本文件约束代码 agent 在项目中的上下文获取与写入行为，防止过度检索与无效 token 消耗。

## 允许获取的上下文（仅三层，禁止额外检索）
1. 目录树：项目文件清单 / 目录结构（用于定位改动点）
2. 相关代码块：与指令相关的函数 / 类 / 组件，以及前后各 10 行上下文
3. 运行报错日志：静态检查 / 测试失败时的错误输出（第三层，仅在失败需要分析时加载）

## 禁止的行为
- 禁止为"确认"而整文件通读与任务无关的代码
- 禁止重复检索同一文件（一次定位、一次读取）
- 禁止在没有报错日志时臆测运行时行为
- 禁止修改与任务无关的文件、目录、依赖
- 禁止为了"更稳妥"把多个无关文件拼进上下文

## 工作流程
1. 先看目录树定位改动点，再读取相关代码块
2. 动手前先在内部完成分析：理解意图 → 定位 → 评估影响 → 再输出代码
3. 输出前对照 COMMON_PITFALLS.md 逐条自检
4. 失败打回时，只根据报错日志修正对应位置，不要重写无关代码

## 输出要求
- 只输出代码 / SEARCH/REPLACE 补丁本身，不要解释
- 写入路径必须是目录树 / 相关代码块中真实存在的文件（新文件按指令明确创建）
