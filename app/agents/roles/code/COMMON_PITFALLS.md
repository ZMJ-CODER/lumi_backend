# 常见编码问题清单（写代码前后自检）

## 导入与依赖
- [ ] import 的模块 / 包真实存在，路径与文件名完全一致（大小写敏感）
- [ ] 用到的第三方库已写入 package.json / requirements.txt / go.mod（依赖清单）
- [ ] 组件文件被 import 且已注册，模板标签与组件名一致

## Vue / 前端
- [ ] template 中引用的方法、数据、事件处理函数都在 script 中定义
- [ ] 修改的是真实存在的文件（不是靠猜的路径；目标文件不存在时先列目录确认）
- [ ] 样式 / 模板改动后 script 部分未被破坏（SFC 三段结构完整）
- [ ] 路由、组件懒加载路径正确

## 类型与语法
- [ ] TS 类型匹配（不要 any 兜底），没有未定义变量 / 拼写不一致
- [ ] 函数、类、组件命名一致，导出与导入匹配
- [ ] 语法完整：括号、引号、分号、缩进风格与项目一致

## 逻辑与边界
- [ ] 增删改查等操作覆盖所有分支（空数据、边界值、异常路径）
- [ ] 异步操作处理了失败与加载状态
- [ ] 不修改与任务无关的代码 / 文件

## 平台差异
- [ ] 路径使用正斜杠或与项目一致的分隔符
- [ ] 注意 Windows CRLF 与跨平台路径问题
