# Lumi 个性化设计

> 版本：v1.0（2026-08-17）
> 主题：办公模式交互、文档编辑预览、个人化设置（角色/声音/外观/记忆/邮件/日历）
> 设计原则：**默认即用、个性化可保存、多端同步、隐私本地优先**

## 1. 双模式产品定位

| 模式 | 定位 | 记忆策略 | 技术链路 |
| --- | --- | --- | --- |
| 普通模式 | 日常问答、闲聊、资料查询 | 超大短期窗口（25 万 token）+ 摘要归档 + 长期记忆 | RAG + 双模型（快速/思考） |
| 办公模式 | 上传文档 → 分析/编辑/产出 | 短期窗口（6 万 token）+ Temporal 任务状态 | 多智能体 DAG + 结构化文档编辑 |

## 2. 办公模式：聊天框文档"挂载"链路

### 2.1 核心交互

用户上传文档后，文档以卡片形式**常驻输入框上方**（类似豆包办公模式），
不随单条消息消失：

- 只要用户不主动取消/删除，后续每一轮对话都携带该文档执行指令；
- 服务端限制挂载轮次（`OFFICE_DOC_MAX_ROUNDS`）与会话 TTL（24h 滑动刷新），双重防堆积；
- 用户在设置中上传的文档走**知识空间（长期保留）**，两条链路互不干扰。

### 2.2 为什么两条链路

- 聊天框上传：临时任务文档，只在当次任务上下文里有效，不留档、不进长期知识库；
- 知识空间：用户主动沉淀的资料，长期保留，供 RAG 检索；
- 这解决了"上传文档后模型看不到""问文档里四个字查不到"等历史问题：
  文档正文随任务携带（≤20KB 全文直注入），知识空间走混合检索 + 硬阈值 0.7。

## 3. 编辑预览与落盘：不可逆操作前必须可撤销

### 3.1 缓冲 + 审核

对 Word/Excel/PPT 的结构化编辑，一律不直接覆盖原文件：

1. 服务端解析文档结构 → LLM 生成编辑指令（OP_SCHEMAS）→ 应用到**缓冲副本**；
2. 前端以 Office 同款样式预览修改后的文档；
3. 用户点击"保留"才提交回原文件；"撤销"则丢弃缓冲；也可直接关闭预览。

### 3.2 前端预览布局

- 用户提出修改文档的需求时，聊天框右侧 **50% 区域**嵌入文档预览页；
- 左侧 50% 显示**压缩后的会话**（基础信息栏隐藏，让位给聊天）；
- 预览样式与 Office 软件一致（docx-preview / pptx-preview / xlsx 纯前端渲染）；
- 预览页提供：保留修改 / 撤销修改 / 关闭预览 / 保存到本地（拿到修改后的版本）。

### 3.3 服务端落盘位置

- 聊天框上传的文档存服务端 `data/office/...`，"直接修改文件系统"改的就是这份服务端副本；
- 前端"保存到本地"可下载修改后的版本；
- 如需改完自动写回用户本机原始路径，走客户端写盘链路（需要本地路径授权）。

## 4. 任务气泡：运行时展开、结束后折叠

办公任务的消息气泡按 4 阶段切换：

1. **任务提交**：生成空任务气泡，详情面板自动展开；
2. **执行中**：摘要层隐藏，详情面板实时流式追加执行日志（步骤、运行命令、检测进度）；
3. **完成**：详情层自动折叠（数据保留不删除），展示精简总结卡片；
4. **手动查看**：点击气泡顶部"耗时 XX分钟XX秒 >"展开/收起完整日志
   （> 折叠 / ∨ 展开，高度过渡动画）。

数据模型：

```json
{
  "msg_id": "xxx",
  "type": "agent_task",
  "status": "running|finished",
  "cost_time": "17分钟18秒",
  "summary": "最终总结报告文本",
  "detail_log": ["步骤1", "运行了命令", "步骤2"]
}
```

## 5. 上传交互：三态卡片

文件卡片分三态（React + TailwindCSS）：

| 状态 | 表现 |
| --- | --- |
| 上传中 | 文件图标 + 文件名 + 进度条（实时百分比）+ 取消按钮（xhr.abort） |
| 上传成功 | 浅灰圆角卡片：类型图标（如 Word 蓝 W）+ 文件名（超长省略）+ `后缀 · 大小`；按类型展示操作按钮（"详细总结文档内容 →"、"生成 PPT →"、"对文档内容进行润色 →" 等） |
| 上传失败 | 错误文字 + 重新上传按钮 |

## 6. 对话个性化：角色 / 头像 / 主题 / 回复风格

### 6.1 角色设定

- 角色提示词可插拔：`app/prompts/*.md`，frontmatter 定义元信息；
- 设置页中可加载角色设定与个人信息（解决"加载不出来"的历史问题）；
- 用户可保存自己的角色方案到服务端，实现多端同步；
- 服务端只存默认方案，不覆盖用户已保存的个性化配置（登录后以服务端个性化配置为准，
  首次使用用默认）。

### 6.2 智能体头像

- 设置中更换头像：用户从本地选图 → 与注册一致裁剪（react-easy-crop）→ 保存；
- 保存后聊天窗口与消息气泡的 AI 头像同步更新；
- 支持移除恢复默认。

### 6.3 主题背景

- 设置中更换全局主题背景图，更换后全局背景立即生效；
- 同样支持移除恢复默认。

### 6.4 回复风格（普通模式）

- 设置中可选"长句一段式"或"多段短句"回复（short/long）；
- 短句模式：多条短句分片推送，配合流式输出，消息按时间片合并存储；
- 仅普通模式生效，办公模式保持任务式气泡。

## 7. 声音个性化

### 7.1 设置能力

- 音色 / 语速 / 音高可调，支持克隆音色（预留）；
- 声音设置独立保存方案，与角色设定一样支持服务端同步；
- 更换头像/主题/声音只影响当前用户，不影响其他用户。

### 7.2 语音链路

- ASR：openai-whisper 本地转写（中文），qwen-turbo 纠错；
- TTS：dashscope cosyvoice / edge-tts 兜底 / 本地 qwen3-tts；
- **流式 TTS**：DS 输出到逗号短句即开始合成，不等整段输出完毕，延迟感知更低；
- 语音通话：快速档 DS Flash 回复 + TTS 播报；视频通话为占位（CallPanel）。

## 8. 邮件客户端偏好

### 8.1 需求背景

Windows 用户可能安装多种邮箱客户端。发邮件时默认打开系统默认客户端，
用户说"用 XX 发"后切换并**保存偏好**（可能下次还用）。

### 8.2 实现

- 数据：`UserPreference.email_client` 字段（alembic 0002 迁移）；
- 设置页：下拉选择 Outlook / Thunderbird / Foxmail / 网易邮箱大师 / Windows 邮件；
- 对话内切换：LLM 识别"用 XX 发"→ 自动更新偏好并持久化；
- 执行：Electron `_openMailClient(client)` 按偏好唤起指定客户端（mailto 草稿）；
- 安全：只"起草"，真正发送由用户在邮箱内确认（符合隐私预期）。

## 9. 真实日历

- `office_calendar` agent + `calendar_manager` 技能：事件库（增删改查）；
- ICS 导出/导入：导出自动保存到下载目录并打开系统日历（Outlook/Google/Thunderbird/苹果日历）；
- ICS round-trip 测试通过（导出→导入→内容一致）；
- 日程文件（.ics）只读分析可用；写回日历应用为后续方向（OAuth 授权后双向同步）。

## 10. 记忆策略（普通 vs 办公）

### 10.1 普通模式

- **短期记忆超大滑动窗口**：`LLM_HISTORY_MAX_TOKENS=250000`，适配 1M 上下文模型，
  最近 3-7 天聊天"过目不忘"；
- **触发压缩**：超 25 万 token 后，把最早超出的 10 万 token 按约 10:1 压缩成
  "剧情梗概"（约 5000 token）归档，上下文始终保留最新 15 万 token 原始记录 + 摘要链；
- **消息按时间片存储**：assistant 的多条短句合并为一个 content 数组，作为一次交互，
  50 轮多句交互只占 50 个对象，上下文管理复杂度大幅降低；
- **长期记忆**：画像（常驻注入）+ 事实库（按需 RAG 召回），隐私分级处理。

### 10.2 办公模式

- **不加长期记忆**：只做短期窗口滑动（6 万 token），保证当次任务连贯；
- **任务状态即记忆**：Temporal 持久化未完成任务，任务级摘要写 Redis
  （按会话最多 8 条）传给下一次规划，比记聊天内容管用得多。

## 11. 个性化配置同步模型

| 配置项 | 默认来源 | 用户覆盖 | 同步 |
| --- | --- | --- | --- |
| 角色设定 | 服务端 `app/prompts` 默认提示词 | 用户保存的方案 | 服务端存储，多端同步 |
| 声音（音色/语速/音高） | 服务端默认音色 | 用户声音方案 | 服务端存储 |
| 智能体头像 | 服务端默认头像 | 用户裁剪上传 | 服务端存储 |
| 主题背景 | 默认主题 | 用户上传图片 | 服务端存储 |
| 回复风格 | 长句（long） | short/long | 服务端存储 |
| 邮件客户端 | 系统默认 | 指定/对话内切换 | 服务端存储 |
| 办公/普通模式记忆 | 首次进入记忆上次选择 | 本地保存（localStorage） | 本机 |

> 要点：服务端保存的是**默认模板**，用户个性化覆盖存在用户维度；
> 退出重进软件后，模式记忆从本地恢复，服务端配置登录后加载（不覆盖用户已有配置）。

## 12. 个性化边界与安全

- 上传的语音/头像/背景图仅本人可见，不进入公共知识空间；
- 语音上传转写与总结结果仅当次会话可见；
- 邮件起草、文件修改等高风险动作保留人工确认门控；
- 所有个性化数据支持随账号注销清理。

## 13. 后续个性化方向

1. 定时早晚报/待办提醒（个性化时间与内容偏好）；
2. 邮件双向同步（授权后直接读写邮箱）；
3. 日历双向同步（Outlook/Google OAuth）；
4. 语音克隆正式开放（声纹授权 + 本地合成）；
5. 记忆可视化编辑（用户可查看/删除自己的长期记忆条目）。
